I learned a lot from doing this assignment, at first I was confused about how the same type of menu could need three completely different scraping methods depending on how the website was built. I learned how CSS selectors can find an HTML element with a class or id and how a sibling selector was needed to connect each Lakeshore heading to the correct menu cards. Hilltop made more sense once I saw how read_html could collect the tables and melt could turn the size columns into rows, but Canal Street was harder because the headless browser had to wait for JavaScript, handle pagination with Show more, read each link attribute, and crawl every item page. I also struggled with fuzzy matching because a high score did not always mean two products were actually the same, so normalization and the match threshold still needed a human in the loop for the uncertain items. The price comparison helped me understand how the cleaned names connected everything and how a merge indicator could separate products into only us, only them, or both for the gap analysis. I still need more practice writing selectors and scraping pages that load with JavaScript because I understand the steps better now but I think finding the correct elements on a new website would still take me a long time.
